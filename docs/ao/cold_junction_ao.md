# AoColdJunction — 冷端温度活动对象（TMP75）

整板唯一 TMP75（地址 0x48）与唯一软 I2C 总线的唯一所有者，为最多 8 路热电偶通道提供
冷端补偿温度。总体设计见 `docs/qp-application-design.md`。

## 1. 基线与范围

| 项目 | 内容 |
| --- | --- |
| 需求 | 周期读取 TMP75 冷端温度并发布；温度失效时以 1 Hz 心跳持续发布无效状态；自愈重试 |
| 独占资源 | `tmp75_board_get_device()` 设备对象 + `i2c_soft` 总线（PA1/PA2 位延时、仅任务上下文） |
| 状态机 | QHsm 手写，2 状态 |
| 扩展变量 | `temp_c`（最近有效温度）、`err_cnt`、`te_tick`（周期 1000 ms） |
| 假设 | TMP75 按上电默认配置运行（9-bit 连续转换，0.5 °C 量化，精度已接受）；应用层不写配置寄存器，将来改分辨率属板级职责（板级初始化写入后延时 ≥`tmp75_conversion_time_ms()` 再返回） |

## 2. 职责与不变量

1. **心跳不变量**：`CJC_SIG` 每 1 s 恰一条（成功=有效温度；连续失败≥3=invalid），
   通道据此既取值又判新鲜度——通道不自设老化计时。
2. **I2C 串行不变量**：所有 `i2c_soft` 事务只发生在本 AO 的 RTC 步内（QV 协作天然串行）；
   不在 ISR 访问（库禁止）。
3. **有效性语义**：`valid=1` 当且仅当最近 `err_cnt < 3` 且存在成功读数且读数落在
   合理性带 -30.0..+85.0 °C 内；恢复后立即 `err_cnt=0` 并回有效。
4. 温度有效性只描述冷端源本身；TC 通道如何消费（状态 5）见 `channel_ao.md`。
5. **配置只读**：应用层从不写 TMP75 配置寄存器（上电默认 9-bit 连续转换即够用）。

## 3. 事件契约（本 AO 相关行）

| 信号 | 参数 | 路由 | 说明 |
| --- | --- | --- | --- |
| `TICK_SIG` | 无 | 静态 `te_tick` 自投 | 周期 1000 ms |
| 输出 `CJC_SIG` | `{float temp_c; uint8_t valid}` | 发布，池A | 8×AoChannel + AoModbus 订阅 |

## 4. 状态机

```text
AoColdJunction (top, 初始 → Starting)
├── Starting   （一次性配置 + 首读）
└── Sampling   （1 Hz 周期采样）
```

| 状态 | entry | 定性含义 |
| --- | --- | --- |
| `Starting` | 首读 + 发布 `CJC_SIG`；arm `te_tick(1000,1000)`（不写 TMP75 配置） | 启动瞬态，只停留一次 |
| `Sampling` | — | `TICK_SIG` → 读→发布 |

| 当前状态 | 事件 | 守卫 | 类型 | 动作 | 目标 |
| --- | --- | --- | --- | --- | --- |
| Starting | entry 内 | 首读失败/越界 | — | `err_cnt=1`，发布 invalid | |
| Sampling | `TICK_SIG` | 读成功且在带内（-30..+85） | 内部 | `err_cnt=0`；`temp_c` 更新；发布 valid=1 | 不变 |
| Sampling | `TICK_SIG` | 读失败/越界 | 内部 | `err_cnt++`；发布 `{temp_c, err_cnt<3}` | 不变 |

动作轨迹（Starting→Sampling）：entry 动作完成即初始转换到 Sampling（Working 结构极简，
无复合超状态）。故障自愈不设故障态：失败仅体现为 `err_cnt` 与 invalid 心跳，读成功即恢复。

## 5. 定时与 RTC

| 项目 | 数值 | 依据 |
| --- | --- | --- |
| `te_tick` | 周期 1000 ms（`armX(1000, 1000)`） | 冷端热时间常数秒级；1 Hz 足够 |
| RTC | 软 I2C 读温度 ≈ 6 字节 ≈ 0.5~3 ms（位延时 5 µs + `wk_delay_us`） | **实测收口**；这是常驻最长 RTC |
| 陈旧超时 | 无（定时器永续、无 disarm 路径） | — |

## 6. 容量

| 项目 | 数值 |
| --- | --- |
| 队列 | 4 槽（tick + 裕量） |
| 事件产生 | 1 Hz `CJC_SIG`（发布共享实体，池A 统一核算） |
| QTimeEvt | 1 |

## 7. 故障路径

| 故障 | 分类 | 处理 |
| --- | --- | --- |
| TMP75 NACK/IO 错 | 合法异常（接线/器件） | `err_cnt++`，≥3 发 invalid；持续自愈重试 |
| 温度越界（-30.0..+85.0 °C 之外） | 合法异常（位翻转/器件异常） | 按读失败计（`err_cnt++`），拦离谱值；带内错值是 I2C 无 CRC 的固有残余 |
| 配置寄存器被扰动（器件单独复位回默认） | **无影响** | 全程按默认配置运行，复位回默认 = 回到在用配置；不存在静默降级面 |
| 上电首读 0 °C 假值窗口 | **已消除** | 板级契约：`board_init()` 返回时至少一次转换已完成（将来板级改配置须延时 `tmp75_conversion_time_ms()`） |
| 上电探测 NACK | 合法异常 | board 层已记录；本 AO 不阻塞启动，靠心跳揭示 |

## 8. 验证矩阵（本 AO）

| 测试 | 激励 | 预期 | 证据 |
| --- | --- | --- | --- |
| 正常心跳 | 上电 | 1 Hz 发布，温度随环境变化 | RTT 日志 |
| 失效注入 | 断开 SDA/SCL | ≤3 s 内 invalid 心跳；TC 通道状态 5 | 拔线实验 |
| 自愈 | 恢复接线 | 下一条心跳即 valid | 日志 |
| 量化步进 | 对照标准温度计 | 9-bit 默认，读数呈 0.5 °C 步进（精度已接受） | 读数对比 |
| 越界注入 | 调试构建伪造越界读数 | 按读失败计，连续 3 次→invalid 心跳 | 调试构建 |
| 上电首读 | 冷启动（环境温度 ≠ 0 °C） | 首条 `CJC_SIG` 即真实值，无 0 °C 假值 | RTT 日志 |
| RTC 压测 | 与 8×100 Hz 并行 | I2C 步不被插入（QV 串行），无总线冲突 | 逻辑分析仪 |
